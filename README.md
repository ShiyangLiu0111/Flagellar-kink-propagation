The "solver" folder contains the "main" file and the "plotsomething" file

After running the "main" file, running the "plotsomething" file will yield the data.

Running the "compare" file and the "shujuchuli" file will result in the data graphs of the paper "Spatio-temporal evolution of the driving force for kink propagation during flagellar filament polymorphic transformation".

Some of the data is too large to be uploaded, but it can be obtained by running the program in the "solver" section.
