In the MatlabCode folder, there are "solver" and "data" folders. 

The "solver" folder contains the "main" file and the "plotsomething" file; the "data" folder contains the "compare" and "shujuchuli" files.

After running the "main" file, running the "plotsomething" file will yield the data in the "data" folder.

Running the "compare" file and the "shujuchuli" file will result in the data graphs of the paper "Spatio-temporal evolution of the driving force for kink propagation during flagellar filament polymorphic transformation".
